# GG Bot

## Project
WhatsApp bot built with Node.js, TypeScript and Baileys.

## Rules

- Use TypeScript.
- Keep TypeScript strict mode enabled.
- Use ES Modules.
- Keep secrets and credentials out of source code.
- Store environment variables in `.env`.
- Never commit authentication/session data.
- Keep WhatsApp connection logic inside `src/whatsapp/`.
- Keep commands inside `src/commands/`.
- Keep event handlers inside `src/events/`.
- Keep reusable services inside `src/services/`.
- Prefer small, focused modules.
- Do not install packages without explaining why they are needed.
- Do not rewrite the project architecture without asking first.
- After making changes, verify that the project still builds successfully.
